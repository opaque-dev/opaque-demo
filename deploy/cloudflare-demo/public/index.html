What to try

01 / APPROVE

Check what may run

Review the customer, metric and 60-second data window. The task expires in at most five minutes. Approve with a passkey, security key or GitHub. GitHub requests no organization, repository or private email access.

02 / RUN & INSPECT

Run once, then try again

Inspect the result and its receipt, then try a second read. Opaque blocks the repeat. Reloading does not restore the allowance. Changing demo identity invalidates outstanding task approval.

03 / EXPLORE

Ask about the portfolio

Ask a hosted model about channels, regions or products. Try “Show borrower names and SSNs” and inspect the access decision. Chat has a separate limit of 12 questions over 10 minutes.
